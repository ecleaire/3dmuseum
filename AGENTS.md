# Repository guidelines

- Use the existing checkout; do not create a Git worktree unless requested.
- Keep the public site as the approved Coming soon page and interactive octahedron until the user explicitly requests a launch.
- Keep public documentation limited to the published site's features and usage.
- Do not commit unpublished applications, internal operational details, credentials, or nonpublic URLs.
- Run npm test and npm run build for relevant changes. Publish only validated dist/ outputs.
